# Dailies

The post tracker for UGC creators running more than one brand deal. Free for 2 brands, Pro $9/mo ($79/yr), Pro Plus $19/mo ($179/yr) with more AI scripts.

- `src/` the website (React + Vite)
- `supabase/schema.sql` database, logins, Free-plan limit
- `supabase/functions/` Stripe checkout, billing portal, webhook
- `LOVABLE.md` handoff brief for continuing the build in Lovable
- `SETUP.md` step by step: how to put it online and start charging
